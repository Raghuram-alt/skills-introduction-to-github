THE QUICK START

Make your first move.

Build with npm run build, then import the ESM bundle or include the browser script.

import anime from './dist/anime.js';

anime({
  targets: '.box',
  translateX: [0, 240],
  rotate: [0, 180],
  duration: 1200,
  easing: 'easeOutCubic',
  delay: anime.stagger(100),
  loop: true,
  direction: 'alternate'
});

Script tag: <script src="dist/anime.min.js"></script> exposes window.anime.

pause()play()restart()seek(ms)reverse()cancel()

Targets accept CSS selectors, elements, collections, or plain objects. Arrays define evenly timed keyframes. Colors support hex and rgb(a); numeric CSS values use px unless unitless. Use matching explicit units for other measurements.
